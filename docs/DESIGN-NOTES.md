# 视觉重设计备忘（未定论，仅记录）

> 2026-10-20 线上截图评审（桌面 1280 / 手机 390）。用户反馈：首页"老土、没有美感"，目标是现有功能做"眼前一亮"。**以下为观察与建议，方向未拍板，后续再调整。**

## 看到的问题（按杀伤力排）

1. **首屏是素材剪影图**——桌面自行车日落、手机沙滩剪影，叠粉色光晕+爱心光斑，十年前婚礼请柬风格。站里全是自己的照片，首屏却用陌生人素材图，这是最大老土来源。
2. **emoji 当图标**——导航（🏠🖼️👣💝）、时间轴节点（🍽✈🎂⭐）、统计条（🚀📷📍📅💰）、事件卡全是 emoji。各平台渲染不一、色彩杂乱 = DIY 模板感。正规做法：统一 SVG 图标集（如 Lucide）。
3. **卡片汤**——首屏卡/事件卡/统计卡全是同一种圆角白卡浮在米色底，间距、形状、权重一样，没有疏密和大小对比 = AI 模板布局，挑不出错但没记忆点。
4. **首屏信息叠 7 层**——LOVING 徽章、生日玻璃盒、TOGETHER FOR、大数字、语录、日期+倒计时、时间轴节点挤在一张图上打架，无主视觉焦点。

**值得保住的**：居中宋体 logo「珍藏回忆 / OUR STORY」、大号衬线数字「2851 Days」、留白与圆角的克制——字体审美在线，问题在图片、图标、布局层次。

## 第二轮：玻璃节点 / 卡片等高 / 两个弹窗（2026-10-22 已改，未提交）

### 时间轴节点 = 磨砂玻璃（`HorizontalTimeline.tsx`）

用户要的是**圆点**的玻璃感，不是卡片的。做法：多层白色渐变（左上薄→右下带一点暖黑）+ `backdrop-filter: blur(18-20px) saturate(1.6-1.85) brightness(0.98/1.14)` + 1px 亮边 + `inset 0 1px 0` 内高光 + 左下镜面高光点（`Glint`）。选中态靠 `brightness` 提亮而不是靠加白，所以照片颜色仍透得上来。

- **踩坑**：祖先元素上有 `mask`（当时的 `.lm-edge-fade-x` 两端淡出）会让 Chrome 建立 backdrop root，`backdrop-filter` 采不到封面照片，圆点会变成纯色圆饼。已删掉遮罩。同理 `filter` / `opacity` 也会。
- 年份标记改成**烟灰玻璃药丸**（深色低透明 + 白描边），在浅色和深色封面上都读得清。

### 事件卡（`EventPreviewCard.tsx`）

- **卡片等高**：照片面板改成固定高度（移动 172 / 桌面 300），不再用 `aspect-ratio`。1/2/3 张现在都是 322（移动）/ 302（桌面）。
- 照片格**不留圆角、3px 缝**，外圈交给卡片 `overflow-hidden rounded-3xl` 裁 —— 整块照片"贴边"，比一格格小圆角更整体。
- **末行补齐**：`n % 列数 !== 0` 时插入「查看相册 →」格，5 张 / 7 张不会再留一个白洞。
- 左栏：眉标（MEMORY）→ 大标题（桌面 22px 衬线）→ 描述（桌面 3 行）→ **2×2 信息网格**（日期/地点/照片/花费）→ 查看详情。桌面端日期从眉标挪进网格，避免重复；移动端仍走顶部日期 + 底部 chips。
- 卡片**没有**改成玻璃 —— 用户明确说那块不急。

### 事件详情（`EventDetail.tsx`）

- 头部图标从橙色实心渐变改成**暖色淡玻璃底**（低透明渐变 + 描边 + 内高光），标题 17px 衬线。

## 第三轮：透明度 / 选中光效 / 卡片与导航栏玻璃（2026-10-22 已改，未提交）

### 节点再透一档

关键认知：**「看起来像玻璃」和「真的透」是两件事**。上一版白渐变厚（0.32 起）+ `saturate(2) brightness(1.02)`，糊出来是个实色粉饼。这版把白色压到 0.26 → 0.06 → 暖黑 0.10，去掉 `brightness` 提亮，`saturate` 降到 1.25 —— 中间几乎全让给照片，只留边、内高光、反光点。

- 选中态也**不靠加白**区分（0.24），靠**更亮的边 + 更大 + 呼吸光晕**。加白会立刻退回"奶白圆饼"。
- 亮封面（日落、雪山）上白色边定不住形，所以未选中补了一道 `0 0 0 1px rgba(50,32,22,0.10)` 外圈暗边 —— 内亮外暗，才是真实玻璃的边。

### 选中光效

节点后面挂一个 `size + 62` 的暖白光晕（`radial-gradient` + `blur(8px)`），配 `@keyframes lm-breathe`（3.6s，opacity .6↔1，scale .93↔1.05）。幅度刻意压得很小，只负责"我在选中"的信号，不抢照片。`prefers-reduced-motion` 由全局 `[style*="animation"]` 规则接管。

### 卡片 / 导航栏玻璃

- `.lm-glass-panel`：白色渐变（0.78→0.50→0.58）+ `blur(18px) saturate(1.35)` + 1px 白边 + `inset 0 1px 0` 内高光 + 暖色投影。**不依赖背景内容**，所以放在纯色奶油底上也不会糊成一片——玻璃感由"亮边 + 内高光 + 顶部渐变"三个材质线索撑住。
- `.lm-glass-bar-top` / `.lm-glass-bar-bottom`：上下导航栏。磨砂感靠内容滑过去才显出来（截图里能看到封面从顶栏下面透上来）。
- 激活态：桌面导航从"淡橙底"改成**白色胶囊 + 1px 白 ring**；底部 tab 在图标后面加一颗 `bg-lm-accent/15` 的胶囊。
- 顺手清掉 `NavBar` 里两处死 token `border-lm-clay/30`（clay 2026-10-19 就删了）。

## 第四轮：选中胶囊 / 卡片左栏（2026-10-22 已改，未提交）

### `.lm-glass-pill`（导航栏 + 底栏选中态）

三条踩过的经验：

1. **伪元素高光会盖住 emoji 和文字**。`::after` 是定位元素，即使 `z-index: 1` 也画在普通行内内容之上 —— 第一版胶囊里的 🏠 被糊成半透明。高光必须画在 `background` 的多层渐变里。
2. **在浅色底上，「加白」只会变成塑料**。玻璃感只能靠三件事：左上镜面光（`radial-gradient`）、一道斜向高光（`linear-gradient(112deg)`）、由上到下由白转暖的**厚度渐变**（`#FFF → #FCEFE4`）。
3. **光晕越宽越像糊了一层**。外阴影收成 `0 1px 2px` + `0 4px 10px -6px`，轮廓才立得住；外圈 `0 0 0 1px rgba(204,146,102,.20)` 定边。

顶栏/底栏底色同时从 0.84 降到 0.76/0.78，胶囊的 `backdrop-filter` 才采得到东西。

### 事件卡左栏

- **根因是内容太短，不是排版太空**：真实描述只有 5–10 个字，永远一行，所以"三行引文"的设想从来没发生过。
- 标题桌面端 22 → **26px**，信息栏行距 7 → 10px、值 12.5 → 13px，把空间用字号吃掉。
- 信息栏从 **2×2 四宫格**改成**标签 · 点线 · 值**的列表（`border-dotted` 引导线 + 右对齐值），像一张手写标签，比表格耐看，也不再有"表单感"。
- 描述左侧的暖色竖线**只在有描述时出现**——空占位旁边挂一根线像 bug。
- 左栏加 `.lm-paper-panel`（极淡暖纸色，仅 md+）和一团 `bg-lm-blush/20` 的暖光，让左栏不是死白。
- 移动端去掉 🖼 / 💰 两个 UI emoji 胶囊，换成 `3 张照片 · ¥520` 纯文字（UI emoji 比事件 emoji 更容易显廉价）。

### 文案

「查看详情」→ **「翻开回忆」**（配 `MEMORY` 眉标，动词开头，和"回忆"主题一致）。备选：`走进那天` / `翻开这段回忆`。

## 第五轮：移动端卡片等高 + 统计栏重做（2026-10-22 已改，未提交）

### 移动端卡片为什么忽高忽低

两个变量：**有没有花费**（多一行 28px）、**描述一行还是两行**（差 21px）。桌面端早就不受影响，因为卡片是 `md:h-[300px]` 写死的，移动端一直是自然高度。

解法：

- 底部元信息行**常驻**，没有花费时只显示「N 张照片」，有花费才加 `· ¥xx`
- 左栏 `min-h-[156px]`（`md:min-h-0`），多出来的空间交给**描述块** `flex-1` + `items-center` 吃掉

第二条是关键。直接把左栏定高、元信息行 `mt-auto` 顶到底，会在描述和元信息之间留一条 40px 的空洞；让描述块自己撑开并垂直居中，空白就均分到上下两侧，读起来是留白而不是"缺了东西"。

实测 5 个事件（有/无花费、有/无描述、1~3 张照片）现在全是 **330px**。

### 统计栏（`StatsSection.tsx`）

原来 5 个彩色渐变胶囊（粉/琥珀/蓝/紫/翠绿），跟整套暖色 + 玻璃完全不搭。

**被否掉的三版**（记下来，别再走一遍）：

| 版本 | 做法 | 否决理由 |
|:--|:--|:--|
| a | 四格数字 + 底下单独一行 SPENT | 「数字一上一下的有点怪」，读起来像两条信息 |
| b | 一块暖色渐变条把四格包进去 | 白边太硬、跟上面那张卡完全不搭（「真的很丑」） |
| c | 四个彩色渐变方块 | 「几个色块太丑了点，完全不搭」 |

**最终版：不铺色、不做卡片，做成一条编辑排版式的数据行**，跟上面那张卡共用一套语言。

- 眉标 `— In numbers`，后面接一条渐隐到右边缘的发丝线 —— 报头感，不再是孤零零一个小标题
- 四个 9px 的**四角刻线**当画框（印刷套准角标），比整圈描边轻，但一眼看得出「被框住了」
- 顶部一层 `radial-gradient` 暖光晕（13% → 0），让这条从米色底上浮起来，不发平
- 每格上方一行 7px 衬线**微编号** `01–04`（`accent-deep/30`），排版的索引感来源
- 竖分隔用**上下渐隐的发丝线**（`via-lm-line`），比虚点轻，也不跟卡片里的点线引导线抢
- 数字 Playfair + `tabular-nums`，26px（移动）/ 34px（桌面）；标签沿用卡片里的英文小字眉标（8px，`tracking-[0.24em]`）
- **第四格是累计花费**：封面上 2853 Days 已经是主角，不重复；没有账单时退回天数，标签改 `Days`，不留空格
- `¥` 用 `0.52em` 靠基线 + `accent-deep/65`，让符号退到数字后面

**顺带修的两个 bug**

- `AnimatedNumber` 的初值写成了 `value`，`diff === 0` 直接 `return` —— **首屏根本不会数上去**。改成从 0 起跳。
- ref 只在动画结束时落定，中途被打断不会把起点写成终点。这就是「主页天数有时候变成 0」的根因（`useAnimatedNum` 同一处反模式，一并修了）。
