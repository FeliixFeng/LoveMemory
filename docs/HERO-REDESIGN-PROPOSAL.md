# 首页（首屏）重塑方案：高定杂志封面与多端自适应设计

> 记录于 2026-11-24。核心目标：彻底解决当前首屏“信息拥挤打架、缺乏视觉焦点、静态缺少生命力”的问题。
> 原则：**移动端优先打磨，桌面端典雅适配；纯 CSS 硬件加速，100% 轻量可行。**

---

## 一、 核心痛点与重构原则

| 当前现状 | 重构后形态 |
| :--- | :--- |
| **元素打架**：天数、情话、倒计时、时间轴全挤在首屏遮罩里 | **画框留给画面**：首屏纯净透气，时间轴移出首屏作为滑动进入的时光门 |
| **万年不变**：没有新事件时每天打开一模一样 | **今日心动**：引入「那年今日」动态信笺卡与「双人便签」，每天打开都有惊喜 |
| **单行白卡**：下方事件卡片偏向传统后台组件 | **杂志画卷**：宽幅旅行画报 + 拍立得照片错落拼贴感 |

---

## 二、 移动端设计（Mobile First，核心战场）

### 1. 首屏构图（杂志封面感）
* **视口控制**：采用 `100dvh` 或微收缩比例，留出底部悬浮磨砂栏。
* **画面层次**：
  * **背景层**：氛围封面大图，配超轻柔的 12s 极缓呼吸微浮动（Ken Burns 微缩放效果）；
  * **顶部**：极小巧的法式小标，标注两人的专属名字（如 `HAIFENG & YUANYUAN`）与当前季节/时节小标；
  * **黄金下沉区**：不再居中死板堆叠。在画面下方 1/3 处：
    * 极细大号法式衬线体（Playfair Display）大数字：`2851`；
    * 伴随字样：`Days of Our Story`；
    * 一句淡雅的情话，底部带一个微弱的下滑提示箭头（向下指引滑动）。

### 2. 滑入第二屏（今日惊喜与时光轴展开）
* **那年今日插页**：手指往下一划，最先映入眼帘的不是干瘪事件，而是一张微微倾斜 1.5° 的拍立得纸笺：
  * *“一年前的今天，你们在东湖看夕阳…”*（附一张老照片缩略图）；
* **时光长廊展开**：紧接着展开磨砂玻璃圆点的时间轴，流畅滑动切换当年的旅程。

---

## 三、 桌面网页版自适应（Desktop Responsive）

桌面端屏幕宽、横向视野大，如果只是按手机端放大，文字会显得巨大且两边留白空洞。因此采用**「双栏杂志编辑版面」**：

* **左栏（40% 宽度，内容画报）**：
  * 优雅的米暖色磨砂玻璃面板；
  * 两个人专属的结婚/恋爱签名印章；
  * 大衬线天数与纪念日倒计时；
  * 嵌入「今日双人便签」与「那年今日」小信封；
* **右栏（60% 宽度，沉浸大画框）**：
  * 16:9 或 4:3 黄金比例的高级画框（带极细发丝描边与多重柔和投影）；
  * 轮播展示高清封面与旅行大片，右下角带有优雅的极细相片计数器（`01 / 06`）。

---

## 四、 技术可行性保障（100% 可落地）

1. **绝对不引入重度 3D/Canvas 库**：
   * 封面微呼吸纯靠 CSS `transform: scale(1.03)` + `will-change: transform`，GPU 硬件加速，移动端 60fps 满帧毫无发热负担；
2. **零布局偏移（CLS = 0）**：
   * 字体采用已内置的自托管 `Playfair Display` + 系统衬线宋体兜底，不会因网络字体下载而发生文字闪烁跳动；
3. **响应式实现轻量**：
   * 移动端 `flex flex-col`，桌面端断点 `lg:grid lg:grid-cols-12` 优雅展开，一套组件响应式兼顾两端。
